# Media Outreach Cadence — Kuberna Labs

Untracked by design. Plan/reciprocity/cadence documents stay out of git.

## Sourcing rule (non-negotiable)

- Only addresses the contact **published themselves** for pitches/sponsorship/tips,
  on their own site, newsletter, or show listing (source recorded below).
- No guessed addresses, no data-broker/scraped-personal addresses, no Gmail-pattern
  guesses. If an address bounces, re-verify on the source page before retrying.
- SEO guest-post farms (businessfirms.co, merehead.com, cryptokiosk, BTC Geek) and
  PR brokers deliberately excluded — they bring links, not audience.

## Cadence

- **Send order:** Tier 1 first, one per half-day (not batched in one hour), Tue–Thu.
- **Touchpoints:** one short useful touchpoint per week, maximum. A skip is valid.
- **Nudge policy:** at most ONE nudge per contact, ~5–7 days later, and only when
  attached to a new datum (PR #108 merged, new benchmark, milestone). Never "just
  checking in."
- **Registry stat rule:** x402 registry ~16,000 resources is a registry observation
  (Sept 2026 survey) — always attributed with link (x402.org), never claimed as ours.
- **Reply handling:** reply same day, short and warm; move thread to relationship
  cadence if they engage.
- **Bounce handling:** re-verify address on source page, retry once. No hunting for
  alternates through brokers.
